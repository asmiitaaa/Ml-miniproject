## Required manual close-out

1. Open every DOI through the institution's IEEE Xplore/Scopus access. Export RIS/BibTeX, compare author order, title, final issue year, pages/article number and DOI, and retain the export with access date.
2. Complete the pending article-level checks above, particularly pasted entries 8, 12, 16, 21 and 22. Read methods/limitations before adding detailed survey claims.
3. For Scopus, retain the actual document identifier or export; a publisher's “view in Scopus” link or an institutional citation count is not a completed Scopus check.
4. Use only cited references in the final report. Do not pad the bibliography with the entire pasted list.
5. Run the institution's Turnitin pre-check on the final student-reviewed report. Record the date and actual similarity score, inspect matched passages and correct attribution as needed. The requested <=15% threshold is **not verified** by this work.
